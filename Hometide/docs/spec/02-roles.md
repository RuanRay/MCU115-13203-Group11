## 2. 使用者角色、權限與使用情境

### 2.1 角色與權限矩陣

| 功能 | 訪客 | 會員 |
|---|---|---|
| 查詢班次（手動、AI、常用路線以外） | ✓ | ✓ |
| AI 一句話查詢 | ✓（每分鐘 5 次） | ✓（每分鐘 5 次） |
| 查看票價、誤點、離線快取 | ✓ | ✓ |
| 收藏常用路線 | ✗（顯示登入提示） | ✓ |
| 設定出發提醒 | ✗（顯示登入提示） | ✓ |
| 下一班分頁 | 顯示「登入後即可使用」引導畫面 | ✓ |
| 國道分頁：查看路況與回家方式比較 | ✓（以空白車票表單選路線，不儲存） | ✓ |
| 國道分頁：收藏開車路線 | ✗（顯示登入提示） | ✓ |
| 我的路線頁 | 顯示「登入後即可使用」引導畫面 | ✓ |
| 個人統計 | 顯示「登入後即可查看」空狀態 | ✓ |
| 意見回饋 | ✓（uid 為空，僅記錄裝置匿名 ID） | ✓ |
| 使用紀錄蒐集 | ✓（uid 為空） | ✓ |
| 深色模式設定 | ✓ | ✓ |

### 2.2 人物誌

- **小明（會員）：** 大二，在桃園讀書、家在臺南，每兩週週五下午搭台鐵回家；希望打開 App 就看到「學校回家」下一班。
- **小華（訪客）：** 第一次使用，想先試查高鐵班次，不想一開始就註冊。
- **阿德（會員）：** 大三，連假開家裡的車從桃園回臺南，有時改搭統聯；出發前想知道國道塞不塞、開車和坐車哪個快。

### 2.3 使用者故事（User Stories）

| 編號 | 角色 | 我想要… | 以便… | 對應需求 |
|---|---|---|---|---|
| US-01 | 訪客 | 不註冊就能查詢班次 | 先試用再決定要不要註冊 | FR-AUTH-04、FR-SRCH-01 |
| US-02 | 會員 | 首頁一點就查常用路線 | 每次返鄉不用重新輸入 | FR-FAV-03 |
| US-03 | 任何人 | 用一句話描述行程 | 不用逐欄填寫 | FR-AI-01～05 |
| US-04 | 任何人 | 一眼看到票價、誤點、哪班已開走 | 快速決定搭哪一班 | FR-RES-01～05 |
| US-05 | 會員 | 在出發前收到提醒 | 不會錯過車班 | FR-RMD-01～05 |
| US-06 | 會員 | 在收藏卡片上看到下一班 | 不用點進去也知道要不要出門 | FR-FAV-04 |
| US-11 | 會員 | 打開「下一班」就看到回家的車還有幾分鐘 | 決定現在要不要出門 | FR-NEXT-01～06 |
| US-12 | 任何人 | 看到國道回家路線的預估時間與塞車路段 | 決定要不要現在出發 | FR-HWY-01～06 |
| US-13 | 任何人 | 比較開車、台鐵、高鐵、客運哪個最快到家 | 選最省時的方式 | FR-HWY-04 |
| US-14 | 任何人 | 查國道客運班次與預估到站 | 不必另外開客運 App | FR-BUS-01～06 |
| US-07 | 任何人 | 沒網路也能看上次查的班次 | 在車站訊號差時也能確認 | FR-OFF-01 |
| US-08 | 任何人 | 回報問題並知道被歸類成什麼 | 確認回饋有被理解 | FR-FB-01～04 |
| US-09 | 會員 | 看到自己的使用時間統計 | 了解自己的使用習慣 | FR-USG-04 |
| US-10 | 任何人 | 晚上用深色模式 | 減少刺眼 | FR-SET-01 |
